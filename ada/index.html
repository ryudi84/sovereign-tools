What This Means

The ADA Title II Deadline

On April 24, 2026, all US state and local government entities with populations of 50,000+ must have websites that conform to WCAG 2.1 Level AA. The DOJ has already begun enforcement — Texas counties have been fined $72,000-$89,000. First-time violations carry penalties up to $75,000; subsequent violations up to $150,000.

Most Common Violations Found

Critical: Invalid ARIA attributes, missing form labels, focusable content hidden from assistive technology.
Serious: Insufficient color contrast, missing link text, images without alt text, keyboard traps.
Moderate: Heading order issues, missing landmark regions, redundant ARIA roles.

Methodology

Each city's homepage was scanned using axe-core, the industry-standard open-source accessibility testing engine. Tests were run against WCAG 2.1 Level A and AA success criteria.

  • 101 US cities with populations over 200,000
  • Scanned March 8, 2026
  • Homepage only (full-site scans would likely reveal more violations)
  • Automated testing covers approximately 57% of WCAG 2.1 AA criteria
  • Full compliance requires manual expert review of remaining criteria
